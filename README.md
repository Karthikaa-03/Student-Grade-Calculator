\# Student Grade Calculator



\## Project Description

The Student Grade Calculator is a beginner-friendly Python mini project that calculates student marks, total, percentage, grade and pass/fail status.



\## Objectives

\- Calculate total marks for five subjects.

\- Calculate the overall percentage.

\- Determine the student's grade.

\- Display pass or fail status.

\- Handle invalid user inputs.



\## Technologies Used

\- Python 3

\- Visual Studio Code



\## Python Concepts Used

\## Grading System



| Percentage | Grade |

|---|---|

| 90–100 | A |

| 80–89.99 | B |

| 70–79.99 | C |

| 60–69.99 | D |

| 35–59.99 | E |

| Below 35 in any subject | Fail |



A minimum of 35 marks in every subject is required to pass.



\## How to Run



1\. Install Python 3.

2\. Download or clone this repository.

3\. Open the project folder in VS Code.

4\. Open the terminal.

5\. Execute:



```bash

python grade\_calculator.py

```
